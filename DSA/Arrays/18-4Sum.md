# 🔢 4Sum

Medium

## Problem Statement

Given an integer array `nums` and an integer `target`, return all unique quadruplets `[nums[a], nums[b], nums[c], nums[d]]` such that:

- `0 <= a, b, c, d < nums.length`
- All four indices are distinct.
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

The answer can be returned in any order and must not contain duplicate quadruplets.

## 🚀 Approach

### Sorting + Two Nested Loops + Two Pointers

The main idea is:

> Fix two elements, then find the remaining two elements using the two-pointer technique.

### Step 1: Sort the Array

Sorting helps us move pointers efficiently and skip duplicate values.

```text
[1,0,-1,0,-2,2]

      ↓ sort

[-2,-1,0,0,1,2]
```

### Step 2: Fix the First Element

Use `i` to select the first element.

Skip duplicate values of `i` to avoid repeating quadruplets.

```java
if (i > 0 && nums[i] == nums[i - 1]) {
    continue;
}
```

### Step 3: Fix the Second Element

Use `j = i + 1` to select the second element.

Skip duplicate values of `j`:

```java
if (j != i + 1 && nums[j] == nums[j - 1]) {
    continue;
}
```

Now two elements are fixed.

### Step 4: Use Two Pointers

Initialize:

```java
int k = j + 1;
int l = nums.length - 1;
```

Calculate the sum using `long` to prevent integer overflow:

```java
long sum = (long) nums[i] + nums[j] + nums[k] + nums[l];
```

- If `sum < target`, increment `k` to increase the sum.
- If `sum > target`, decrement `l` to decrease the sum.
- If `sum == target`, store the quadruplet and move both pointers.

### Step 5: Skip Duplicates

After finding a valid quadruplet, skip repeated values for both `k` and `l`.

This ensures that each unique quadruplet appears only once.

## 💻 Java Solution

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {

        Arrays.sort(nums);
        List<List<Integer>> list = new ArrayList<>();

        for (int i = 0; i < nums.length; i++) {

            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            for (int j = i + 1; j < nums.length; j++) {

                if (j != i + 1 && nums[j] == nums[j - 1]) {
                    continue;
                }

                int k = j + 1;
                int l = nums.length - 1;

                while (k < l) {

                    long sum = (long) nums[i] + nums[j]
                            + nums[k] + nums[l];

                    if (sum < target) {
                        k++;
                    } else if (sum > target) {
                        l--;
                    } else {
                        list.add(Arrays.asList(
                                nums[i], nums[j], nums[k], nums[l]
                        ));

                        k++;
                        l--;

                        while (k < l && nums[k] == nums[k - 1]) {
                            k++;
                        }

                        while (k < l && nums[l] == nums[l + 1]) {
                            l--;
                        }
                    }
                }
            }
        }

        return list;
    }
}
```

## ⏱️ Complexity Analysis

### Time Complexity

- Sorting: `O(n log n)`
- Two nested loops and two-pointer traversal: `O(n³)`

**Overall: `O(n³)`**

### Space Complexity

- Auxiliary space: `O(1)` excluding sorting implementation details and the output list.
- Output space depends on the number of unique quadruplets.

## 🌟 Key Points

- **4Sum = Fix two elements + Two Pointers.**
- Sort the array before searching.
- `i` fixes the first element.
- `j` fixes the second element.
- `k` is the left pointer.
- `l` is the right pointer.
- Use `long` for the sum to avoid integer overflow.
- Skip duplicates at all four positions.
- Time complexity: `O(n³)`.

### 🧠 Pattern

```text
4Sum
  ↓
Sort
  ↓
Fix i
  ↓
Fix j
  ↓
Two Pointers (k, l)
  ↓
Check sum and skip duplicates
```

## ⚠️ Common Mistakes

- Forgetting to sort the array.
- Incorrectly skipping duplicate values.
- Using `int` for the sum, which can overflow.
- Moving the wrong pointer.
- Forgetting to move both pointers after finding a valid quadruplet.
- Using three nested loops without the two-pointer optimization, resulting in `O(n⁴)` time.

## 🎯 Interview Tip

Remember:

> **3Sum = Fix one + Two Pointers.**
>
> **4Sum = Fix two + Two Pointers.**

The general pattern is to reduce a `k`-Sum problem into a smaller Sum problem while using sorting to handle duplicates.
