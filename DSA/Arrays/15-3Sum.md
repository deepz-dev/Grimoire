# 🔢 3Sum

## 🔗 Problem Link

<a href="https://leetcode.com/problems/3sum/description/" target="_blank">LeetCode 15: 3Sum</a>

## 🏷️ Tags

- Array
- Sorting
- Two Pointers
- Duplicate Handling

## 📊 Difficulty

Medium

## Problem Statement

Given an integer array `nums`, find all unique triplets:

`[nums[i], nums[j], nums[k]]`

such that:

- `i != j`
- `i != k`
- `j != k`
- `nums[i] + nums[j] + nums[k] == 0`

The answer must not contain duplicate triplets.

## 🚀 Approach

### Sort + Two Pointers

The main idea is:

> **Fix one element, then solve the remaining 2Sum problem using two pointers.**

### Step 1: Sort the Array

Sorting helps us:

- Use the two-pointer technique.
- Easily skip duplicate values.

Example:

```text
[-1, 0, 1, 2, -1, -4]

        ↓ sort

[-4, -1, -1, 0, 1, 2]
```

### Step 2: Fix the First Element

Use `i` to fix one number.

Then initialize:

```text
j = i + 1
k = nums.length - 1
```

Now we need to find two numbers that complete the sum to `0`.

### Step 3: Use Two Pointers

Calculate:

```text
sum = nums[i] + nums[j] + nums[k]
```

If:

```text
sum < 0
```

We need a larger sum, so move `j` forward:

```text
j++
```

If:

```text
sum > 0
```

We need a smaller sum, so move `k` backward:

```text
k--
```

If:

```text
sum == 0
```

We found a valid triplet.

Add it to the answer and move both pointers.

### Step 4: Skip Duplicates

We must avoid adding the same triplet multiple times.

For the fixed element:

```java
if (i > 0 && nums[i] == nums[i - 1]) {
    continue;
}
```

After finding a valid triplet, skip duplicate values for both pointers.

```java
while (j < k && nums[j] == nums[j - 1]) {
    j++;
}

while (j < k && nums[k] == nums[k + 1]) {
    k--;
}
```

## 💻 Java Solution

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {

        List<List<Integer>> list = new ArrayList<>();

        Arrays.sort(nums);

        for (int i = 0; i < nums.length; i++) {

            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int j = i + 1;
            int k = nums.length - 1;

            while (j < k) {

                int sum = nums[i] + nums[j] + nums[k];

                if (sum < 0) {
                    j++;
                }

                else if (sum > 0) {
                    k--;
                }

                else {
                    list.add(Arrays.asList(nums[i], nums[j], nums[k]));

                    j++;
                    k--;

                    while (j < k && nums[j] == nums[j - 1]) {
                        j++;
                    }

                    while (j < k && nums[k] == nums[k + 1]) {
                        k--;
                    }
                }
            }
        }

        return list;
    }
}
```

## ⏱️ Complexity Analysis

### Time Complexity

```text
Sorting       → O(n log n)
Two Pointers  → O(n²)

Overall       → O(n²)
```

### Space Complexity

```text
Auxiliary Space → O(1)
```

Ignoring the space required for the output list.

## 🔒 Constraints

- `3 <= nums.length <= 3000`

## 🌟 Key Points

- **3Sum = Fix one element + Two Sum.**
- Sort the array first.
- `i` → fixed element.
- `j` → left pointer.
- `k` → right pointer.
- `sum < 0` → `j++`.
- `sum > 0` → `k--`.
- `sum == 0` → store the triplet.
- Skip duplicates to avoid duplicate triplets.
- Optimal time complexity is **O(n²)**.

### 🧠 Pattern

```text
3Sum
  ↓
Sort
  ↓
Fix i
  ↓
Two Pointers
  ↓
j + k
```

## ⚠️ Common Mistakes

- Forgetting to sort the array.
- Moving the wrong pointer.
- Forgetting to skip duplicate `i` values.
- Forgetting to skip duplicate `j` and `k` values.
- Using three nested loops, resulting in `O(n³)`.

## 🎯 Interview Tip

Remember:

> **3Sum → Sort → Fix one → Two pointers → Skip duplicates.**

```text
sum < 0  → need bigger → move j right
sum > 0  → need smaller → move k left
sum == 0 → found answer
```
